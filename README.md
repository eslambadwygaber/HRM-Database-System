Human Resource Management (HRM) Database System
Project Overview
This project features a comprehensive relational database designed to manage Human Resource operations. It covers employee records, payroll processing, performance evaluation, and training management.

Core Features
Employee Management: Detailed tracking of employee personal data and department assignments.

Payroll & Benefits: Automated calculation of base salaries, bonuses, and net pay.

Attendance & Leave: Monitoring daily check-ins and managing various types of leaves.

Performance Tracking: Scoring system and feedback loops for employee development.

Training & Development: Managing professional skills and trainer assignments.

Database Schema & Architecture
The system consists of 14 interconnected tables optimized for data integrity and performance.
